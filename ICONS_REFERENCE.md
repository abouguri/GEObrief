# Lucide Icons Dependency

The landing page uses the following Lucide React icons:
- `ArrowRight`
- `Zap`
- `TrendingUp`
- `FileText`
- `BarChart3`
- `Shield`

These are imported from the `lucide-react` package.

**Update to package.json (if not auto-installed):**
```json
"lucide-react": "^latest"
```

**Installation:**
```bash
npm install lucide-react
```
